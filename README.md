# valuehomes

A lightweight PHP + MySQL customer relationship management panel for tracking property leads, client status, and follow-ups.

## Installation

1. Clone the repo and place it under your PHP-enabled web server document root.
2. Import `connection.php` database settings to match your MySQL instance.
3. Create the `users` and `client` tables used by the signup, login, and dashboard pages.
4. Start the local web server and open the app in a browser.

## Usage

- Sign up from `signup.php`.
- Log in from `index.php`.
- View active leads in `home.php`.
- Add a new lead in `details.php`.
- Edit a lead from the `Edit` action in the home table.
- Deactivate a lead from `status.php`.
